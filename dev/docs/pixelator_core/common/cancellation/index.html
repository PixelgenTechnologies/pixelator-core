Module cancellation 

Source
Expand description

Cooperative cancellation of long-running algorithms.

A caller wraps a computation in run_with, handing it a CancellationToken. Hot loops inside the computation call checkpoint; once the token is cancelled, the next checkpoint unwinds the stack and run_with returns Err(Cancelled). The algorithms themselves need neither a token parameter nor a Result return type.

This relies on unwinding, so the crate cannot be built with panic = "abort".

The token is stored per thread: checkpoints reached from other threads (e.g. rayon workers) are no-ops.
