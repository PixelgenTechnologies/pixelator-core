Expand description

Finds low-degree nodes that look like sequencing errors of a nearby UMI, and the UMI each should be corrected to.

A sequencing error in a UMI creates a new node with few edges. A node is investigated when its degree is at most max_degree. It is treated as an error when some node at a positive even distance of at most bfs_threshold hops has a UMI within hamming_threshold symbols of its own. Even distance keeps the candidate on the investigated node’s side of the bipartite graph. max_degree of 1 investigates only leaves.

The first element of the result maps each collapsed UMI to its corrected UMI. It is flat: a chain A -> B -> H is stored as A -> H and B -> H, and a match that would close a loop is dropped.

The second element counts what the search did, for this graph only:

  • nodes_considered is the number of nodes with degree at most max_degree.
  • targets_found and both distance distributions describe the matches that were kept, one entry per kept match. A match dropped because it would close a loop is not counted.
  • Each distance is that of the match as found, so A -> B -> H records the distances of A -> B and B -> H, not of the flattened A -> H.

total_components is left at 0. The graph is not known to be one component, so the caller counts components and adds them with CollapseStats::add_components.
